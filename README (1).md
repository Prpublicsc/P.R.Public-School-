# P.R. Public School

Single-page website for P.R. Public School, Pindohari, Mau, Uttar Pradesh.

- Self-contained: all images are embedded in `index.html` (about 1.5 MB)
- Only external dependency: Google Fonts (falls back to system fonts offline)
- No build step

## Publish with GitHub Pages

1. Upload `index.html` (and this README) to the root of your repository.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
4. The site goes live at `https://<username>.github.io/<repo>/` within a minute or two.
